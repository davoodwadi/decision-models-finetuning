# WVS Wave 7 United States data notes

## Source files and provenance

This directory contains official World Values Survey Association (WVSA) releases for the United States Wave 7 survey alongside the verified audit and export files. The official US Stata dataset [WVS_Wave_7_United_States_Stata_v5.1.dta](./WVS_Wave_7_United_States_Stata_v5.1.dta) (extracted from [F00013106-WVS_Wave_7_United_States_Stata_v5.1.zip](./F00013106-WVS_Wave_7_United_States_Stata_v5.1.zip)) carries authoritative respondent answers alongside embedded WVSA value labels. Two official US PDF documents accompany it. The field questionnaire [F00008646-WVS7_Questionnaire_USA_2017_English.pdf](./F00008646-WVS7_Questionnaire_USA_2017_English.pdf) is the master English form and leaves generic placeholders (e.g., Option 1 through Option 5) on country-coded items such as Q272. By contrast, the official US codebook and results report [F00010562-World_Values_Survey_Wave_7_2017-2020_United_States_v3.0.pdf](./F00010562-World_Values_Survey_Wave_7_2017-2020_United_States_v3.0.pdf) provides complete verbatim US question wording, filled-in US response options, and marginal distributions for Q1 through Q290. The official cross-national release is also archived in [F00011356-WVS_Cross-National_Wave_7_csv_v6_0.zip](./F00011356-WVS_Cross-National_Wave_7_csv_v6_0.zip).

An earlier build had combined official numeric responses with question text and option labels scraped by the third-party WorldValuesBench repository. Because WorldValuesBench was not produced by WVSA, its scraped metadata introduced transcription and parsing errors that do not exist in the official WVSA release. That legacy build and its WorldValuesBench files have been removed from this directory.

## Verification of the official Stata release against the retired build

Direct verification confirmed that [WVS_Wave_7_United_States_Stata_v5.1.dta](./WVS_Wave_7_United_States_Stata_v5.1.dta) and the retired parquet covered the exact same 2,596 US respondents, with a 100 percent match between `D_INTERVIEW` in the Stata file and `CASEID`. All 44 persona columns from the retired build were present in the official Stata release. Furthermore, the Stata file encodes negative survey missing codes (-1 through -5) as Stata extended missing values, so reading it with `pandas.read_stata(..., convert_categoricals=False)` decodes every missing code cleanly to `NaN` with zero unmasked negative codes remaining.

Across all 30 audited persona columns, 23 columns had identical decoded labels in both files, while seven columns differed in ways that fixed third-party WorldValuesBench defects or reflected official US wording. On Q286 (family savings), the official Stata label for code 3 is "Spent some savings", correcting the WorldValuesBench `codebook.json` typo that mislabeled code 3 as "Spent some savings and borrowed money". On Q274 (number of children), the official Stata file stores clean numeric values from 7 to 15 above "6 children", eliminating the WorldValuesBench scrape bug that mapped value 7 to "25.- 7 or more children". On Q269 (citizenship), the official Stata labels are directly "Yes" and "No" rather than the verbose wording "Yes, I am a citizen of this country" and "Not, I am not a citizen of this country". On Q279 (employment status) and Q280 (spouse employment status), the official US Stata label is "Homemaker not otherwise employed" instead of "Housewife not otherwise employed". On Q288 (household income scale), the official label uses consistent capitalization ("Second step" instead of "second step"), though the official WVSA Stata file itself retains minor spelling quirks on "Eight  step" and "Nineth step". Finally, on Q289 (religion), the official Stata file uses "Catholic (Roman/Greek/etc)" and "Other Christian (Jehova withness...)" rather than "Roman Catholic" and "Other Christian (Evangelical/Pentecostal/Fee church/etc.)".

## Finalized pipeline

Persona loading reads [WVS_Wave_7_United_States_Stata_v5.1.dta](./WVS_Wave_7_United_States_Stata_v5.1.dta) through `load_raw_wvs7_personas` in `code/data/persona_loaders.py`, and only `persona_spec.yaml` attributes are kept (29 populated persona columns). The training questions are built from the same Stata file (answers, answer options, and codes) and from the US codebook PDF [F00010562-World_Values_Survey_Wave_7_2017-2020_United_States_v3.0.pdf](./F00010562-World_Values_Survey_Wave_7_2017-2020_United_States_v3.0.pdf) (question wording). [build_question_catalog.py](./build_question_catalog.py) writes [wvs7_questions.json](./wvs7_questions.json) and the starting [question_audit.csv](./question_audit.csv). The exporter `code/data/wvs_export.py` applies the verified audit and [question_overrides.json](./question_overrides.json), then writes [wvs7_US_long.parquet](./wvs7_US_long.parquet) (642,775 rows, 2,596 respondents, 252 questions, 29 persona columns) and [questions_verified.csv](./questions_verified.csv). `code/data/wvs.py` loads the rebuilt standardized parquet directly. Every choice made during the rebuild and audit is recorded in [DECISIONS.md](./DECISIONS.md).
