# NCI HINTS 7 (2024) layout and pipeline notes

## Directory contents and authoritative files

The folder contains a single self-contained official archive, [HINTS7_STATA_20250731.zip](./HINTS7_STATA_20250731.zip) (21 MB, released July 31, 2025), for the National Cancer Institute Health Information National Trends Survey (HINTS 7, fielded in 2024). No additional downloads are required because the archive packages the full public Stata microdata file together with both the annotated English instrument and the complete codebook.

Three entries inside [HINTS7_STATA_20250731.zip](./HINTS7_STATA_20250731.zip) drive the persona and question pipeline. The microdata file `hints7_public.dta` (28.1 MB) contains 7,278 respondents across 470 columns with 403 embedded Stata value label sets. The 25-page `HINTS 7 Annotated English.pdf` prints the exact verbatim English questionnaire layout for Sections A through R with every Stata variable name printed inline next to its question stem and response options. The 566-page `HINTS 7 Public Codebook.pdf` provides the full variable dictionary, exact skip notes, unweighted response frequencies, and derived variable definitions.

The remaining four PDFs inside the archive are supplemental reference documents not needed by the automated exporter, namely `HINTS 7 Annotated Spanish.pdf` (Spanish instrument), `HINTS 7 Methodology Report.pdf` (sampling design and weighting details), `HINTS 7 Survey Overview Data Analysis Recommendations.pdf` (recommended variance estimation practices), and `HINTS 7 History Document.pdf` (cross-cycle item history).

## Dataset layout and sample structure

Each row in `hints7_public.dta` is one adult U.S. respondent identified by `HHID` (`N = 7,278`), sampled through a nationally representative address-based sampling frame. Survey administration mode (`FormType`) splits cleanly between standard web (`FormType = 5`, `n = 4,861`) and standard paper (`FormType = 2`, `n = 2,417`). Unlike ANES 2024, both web and paper respondents answered the same core instrument without separate paper-only variable columns. Language of completion (`Language_Flag`) is overwhelmingly English (`n = 6,978`), with smaller Spanish (`n = 199`) and mixed web (`n = 101`) subsets. The file also records two survey-methodology experimental flags, `Treatment_H7_1` (extra incentive group, `n = 1,035`) and `Treatment_H7_2` (commitment statement group, `n = 1,513`), which affect survey participation rather than question wording.

Columns in `hints7_public.dta` fall cleanly into seven structural groups totaling 470 variables.

| Column group | Column count | Role in dataset |
| --- | --- | --- |
| Respondent ID, design, and geography | 22 | Unique identifier (`HHID`), mode and language flags (`FormType`, `Language_Flag`), sampling strata (`APP_REGION`, `VAR_STRATUM`, `VAR_CLUSTER`), experimental indicators, and Census/USDA/NCHS geography (`CENSREG`, `CENSDIV`, `NCHSURCODE2013`, `PR_RUCA_2010`, `RUC2023`) |
| Sections A through Q single-choice items | 155 | Core substantive survey questions with two or more discrete labeled options (Likert scales, frequency scales, binary yes/no attitudes, and categorical choices) |
| Sections A through Q multi-select checkboxes | 137 | Check-all-that-apply items coded as separate binary columns with value labels `1` Selected and `2` Not selected |
| Sections A through Q numeric or open-text items | 17 | Continuous self-reports (e.g., height, weight, fruit/vegetable servings, days of exercise, drinks per week) and free-text specify fields |
| Section R demographics | 44 | Respondent sociodemographic and background items (`R1` through `R16`), including age, birth sex, education, marital status, occupation, race/ethnicity, household counts, sexual orientation, political viewpoint, and household income |
| Derived scales and recodes | 43 | Official NCI summary recodes at the tail of the dataset (e.g., `EducB`, `RaceEthn`, `RaceEthn5`, `HHInc`, `IncomeRanges_IMP`, `Occupation2_Cat`, `AgeGrpA`, `AgeGrpB`, `BMI`, `phq4`, `PCCScale`) |
| Survey weights and jackknife replicates | 52 | Full-sample weight (`Weight`, `PERSON_FINWT0`) plus 50 jackknife replicate weights (`PERSON_FINWT1` through `PERSON_FINWT50`) |

All HINTS 7 missing, skipped, and error responses are encoded as explicit negative integers rather than Stata extended missing values, so loading with `pandas.read_stata(..., convert_categoricals=False)` preserves every distinction without ambiguity. Negative codes are `-9` (Missing data, Not Ascertained), `-7` (Missing data, Web partial, Question Never Seen), `-6` (Missing data, Filter Missing), `-5` (Multiple responses selected in error), `-4` (Unreadable or non-conforming numeric response), `-2` (Question answered in error, Commission Error), and `-1` (Inapplicable due to skip logic). Any value strictly below zero must be excluded from valid response options during both persona extraction and question export.

## Where persona attributes should come from

All respondent persona attributes come directly from `hints7_public.dta`, keyed on `HHID` as `CASEID` with `country` fixed to `United States`. Geographic region and objective urbanicity are populated for all 7,278 rows from the sampling frame, while Section R self-reported demographics have valid counts around 6,339 to 6,705 because of paper item nonresponse and web partial drop-off (`-7` Question Never Seen). HINTS 7 locks 15 canonical `persona_spec.yaml` attributes in `persona_loaders.py`, notably including a 7-point political ideology measure (`PoliticalViewpoint`, `R15`) and sexual orientation (`SexualOrientation_Recode`, `R12`), while omitting `political_party`, `religion`, `religious_attendance`, and `state`.

| Canonical `persona_spec.yaml` attribute | Locked HINTS 7 source | Valid `n` (of 7,278) | Notes and audit decisions |
| --- | --- | --- | --- |
| `country` | Constant (`United States`) | 7,278 | Entire study is a nationally representative U.S. adult sample |
| `region` | `CENSDIV` | 7,278 | Exact 9 U.S. Census divisions matching ISSP `US_REG`; `CENSREG` (4 regions) and `APP_REGION` were excluded |
| `urban_rural` | `NCHSURCODE2013` | 7,278 | Objective 6-level NCHS 2013 metro/non-metro scale with 100% coverage; `PR_RUCA_2010` and `RUC2023` were excluded |
| `age` | `Age` (`R1`) | 6,665 | Exact integer age in years (18 to 102), auto-binned via `persona_spec.yaml`; `AgeGrpA` and `AgeGrpB` were excluded |
| `gender` | `BirthSex` (`R3`) | 6,663 | Mapped `1` Female and `2` Male, with `3` Don't know (`n = 44`) set to missing; no separate gender-identity column (`R2`) is released publicly |
| `education` | `Education` (`R8`) | 6,695 | Full 7-level schooling item preserving vocational/technical training and both sub-high-school brackets; `EducA` and `EducB` were excluded |
| `family_income` | `IncomeRanges` (`R16`) | 6,379 | Verbatim combined pre-tax annual family income in 9 brackets (`$0 to $9,999` through `$200,000 or more`); `HHInc`, hot-deck `IncomeRanges_IMP`, and subjective `IncomeFeelings` were excluded |
| `race` | Raw `R10` multi-select checkboxes | 6,477 | Aggregated into the 5 canonical U.S. race categories (combining `AsInd` through `OthAsian` into Asian and `OthPacIsl` into Native Hawaiian or Other Pacific Islander) joined with `"; "` for multiracial respondents; `Race_Cat2`, `RaceEthn`, and `RaceEthn5` were excluded |
| `hispanic` | `Hisp_Cat` (`R9`) | 6,484 | Mapped to `No` (`10`) and `Yes` (`21` through `25`), verified 100% consistent with `NotHisp` and subgroup checkboxes |
| `marital_status` | `MaritalStatus` (`R7`) | 6,686 | 6 canonical categories (`Married`, `Living with a partner`, `Divorced`, `Widowed`, `Separated`, `Never married`) |
| `employment_status` | `Occupation2_Cat` (derived from `R5`) | 6,705 | 9 categories from `R5` (`In paid work`, `Out of work for 1 year or more`, `Out of work for less than 1 year`, `Homemaker`, `Student`, `Retired`, `Not working (disabled)`, `Multiple employment statuses`, `Other`) |
| `political_ideology` | `PoliticalViewpoint` (`R15`) | 6,427 | Exact 7-point scale from `Very liberal` through `Very conservative` |
| `household_size` | `TotalHousehold` (`R13`) | 6,676 | Exact integer count of people living in the household (1 to 11), auto-binned |
| `children_in_household` | `ChildrenInHH` (`R14`) | 6,591 | Exact integer count of children under age 18 in the household (0 to 32), auto-binned |
| `sexual_orientation` | `SexualOrientation_Recode` (`R12`) | 6,339 | New canonical attribute (`Straight`, `Gay or lesbian`, `Bisexual`, `Other`, with `Don't know` mapped to missing); raw `SexualOrientation2` was excluded |

For `employment_status`, `Occupation2_Cat` was chosen over `FullTimeOcc2_Cat` because it stays purely derived from `R5` and retains 434 more valid respondents (`n = 6,705`, 92.1%, versus `n = 6,271`, 86.2%), since `FullTimeOcc2_Cat` sets respondents to missing whenever `R4` work hours are skipped or conflict with `R5`. `Occupation2_Cat` also matches the `In paid work` category used in ISSP. The downside for future review is twofold. First, `Occupation2_Cat` collapses all employed respondents into a single `In paid work` category rather than separating `Full-time employed` (`n = 2,767`) from `Part-time employed` (`n = 713`), which reduces direct label overlap with Twin-2K and WVS7. Second, it places 687 respondents (about 10% of valid responses) into `Multiple employment statuses`, a catch-all label absent from every other dataset, whereas `FullTimeOcc2_Cat` resolves overlapping selections into a primary status using reported work hours. Note also that `political_party`, `religion`, `religious_attendance`, and `state` are not collected or not publicly released in HINTS 7, so downstream evaluation on HINTS 7 tests demographic and ideological polarization without relying on party ID or religion.

## Where questions should come from

Candidate survey questions span Sections A through P (excluding Section R demographics and Section Q personal cancer-history details), totaling 155 single-choice discrete items before domain screening. Because HINTS 7 is a public health and health-communication survey, its sections fall cleanly into two groups for a Psychology and Marketing silicon-sampling benchmark, namely high-value attitudinal, consumer-technology, media, trust, and belief batteries versus purely clinical or personal medical-history items.

The strongest candidate batteries for attitudinal and consumer-behavior evaluation come from eight sections with broad full-sample coverage (`n` around 6,600 to 7,200). Section A covers institutional trust in doctors, family, government agencies, charities, religious organizations, and scientists (`A3a` through `A3f`, `CancerTrust*`), plus perceived conflict and instability in expert recommendations (`A4` `HealthRecsConflict` and `A5` `HealthRecsChange`). Section B covers consumer technology and social media behavior and beliefs (`B1` through `B14d`), including internet use, device and smartwatch adoption, digital literacy (`B5a` through `B5c`), health and wellness apps (`B7`), wearable tracking and willingness to share wearable data (`B8`, `B10`, `B11`), social media usage (`B12a` through `B12e`), perceived health misinformation on social media (`B13` `MisleadingHealthInfo`), using social media for decisions (`B14a` through `B14c`), and social media echo chambers (`B14d` `SocMed_SameViews`). Section D and Section E cover telehealth attitudes, willingness, and satisfaction (`D4a` through `D6`) alongside digital patient-portal access and comfort viewing test results online (`E1a` through `E11`). Section H measures trust and suspicion toward clinical trials (`H3` `ClinicalTrials_Suspicion`). Section J covers climate change health harm, extreme weather, and air pollution worry (`J1` through `J3b`). Section K captures household financial, food, housing, transportation, and medical-bill hardship (`K1a` through `K1d`) and privacy comfort with healthcare providers documenting or sharing those issues (`K2a` and `K2b`). Section N (`N10` marijuana harm beliefs and federal court warning message beliefs), Section O (`O5` through `O8` screening preferences and multi-cancer test valuation), and Section P (`P1a` through `P1d` cancer fatalism and recommendation overload beliefs) round out the attitudinal pool.

Three categories of columns in Sections A through Q must be filtered or explicitly audited before export. First, all 137 check-all-that-apply binary columns (`Selected` versus `Not selected`) should be excluded from standard single-choice choice and score tasks unless specifically designed as binary yes/no items, because paper and web respondents evaluate them as checkboxes rather than mutually exclusive choices. Second, purely clinical or personal-history items (e.g., personal cancer diagnosis in Section Q, chronic condition diagnoses in `I5a` through `I5f`, sunburn counts, height, weight, servings of fruit, and drinks per week in Sections L and M) measure private medical facts rather than consumer attitudes or beliefs and should be dropped during `question_audit.csv` triage. Third, skip-gated follow-up questions apply only to conditioned subsamples (e.g., `A2a` through `A2d` are asked only of prior cancer-info searchers, `n = 3,660`; `B9` and `B10` only of wearable owners, `n = 2,660`; `B14a` through `B14d` only of social-media users, `n = 5,946`; `D4a` through `D4d` only of telehealth users, `n = 2,400`; `E4` through `E6` only of portal users, `n = 4,800`). Keeping the skip condition explicit in the audit notes prevents silent population mismatch when comparing marginal distributions across demographic groups.

Verbatim question stems should be parsed from the 25-page `HINTS 7 Annotated English.pdf` rather than relying solely on the 80-character Stata variable labels. Although almost every Stata variable label helpfully starts with its questionnaire item number (e.g., `A3c. In general, how much would you trust...` or `B14d. How much do you agree or disagree...`), Stata truncates longer stems and omits shared matrix headers and lead-in instructions. Because `HINTS 7 Annotated English.pdf` prints exact Stata variable names directly beside each verbatim question and grid header, deterministic extraction joined on the Stata variable name is straightforward and much cleaner than multi-hundred-page CAPI specifications.

## Where response options should come from

Response options and exact integer answer codes come directly from the embedded Stata value label sets (`reader.value_labels()` mapped via `reader._lbllist`) in `hints7_public.dta`, verified against `HINTS 7 Annotated English.pdf` and `HINTS 7 Public Codebook.pdf`. Keeping only codes strictly greater than or equal to zero (`code >= 0`) automatically removes all seven negative missing, skip, and error categories (`-9` through `-1`).

## Finalized export and audit pipeline

The HINTS 7 catalog, audit, and export pipeline is finalized and reproducible from [HINTS7_STATA_20250731.zip](./HINTS7_STATA_20250731.zip) without any external dependencies. The catalog builder [build_question_catalog.py](./build_question_catalog.py) parses verbatim stems, section headers, and response options from `HINTS 7 Annotated English.pdf` joined to `hints7_public.dta` into [question_audit.csv](./question_audit.csv), excluding all Section R persona columns from substantive questions while flagging them separately in the Audit UI. Two Stata 80-character value label truncations caught by the Audit UI Source check (`ExpClinTrial` options 2 and 3, and `PrefCervCaTest` option 2) are repaired cleanly via [question_overrides.json](./question_overrides.json), and response option formatting uses the shared [format_option_texts](../option_labels.py) helper so explicit numeric frequency labels such as `AccessOnlineRecord3` (`0`, `1 to 2 times`, `3 to 5 times`, `6 to 9 times`, `10 or more times`) stay verbatim.

Running `python -m data.hints7_export` produces [hints7_long.parquet](./hints7_long.parquet) and [questions_verified.csv](./questions_verified.csv) with 952,561 respondent-question rows across all 7,278 respondents, 155 included questions (84 `score` and 71 `choice`), 15 standardized `persona_spec.yaml` persona columns, zero missing answers, and zero code or text mismatches. Downstream training and evaluation code loads the standardized parquet directly via [load_hints7_df](../hints7.py) and [load_hints7_eval](../hints7.py).
